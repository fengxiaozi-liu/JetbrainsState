GoLand 2026.3 原 EXE 启动配置包

适配范围
  Windows x64，GoLand GO-263.7307.211。
  当前安装脚本固定检查以下目录：
  C:\Program Files\JetBrains\GoLand 2026.3
  若产品构建或安装目录不同，本包不能直接通用。
  包内不包含 GoLand 软件本体。

文件说明
  install-for-exe.cmd     一次性安装入口，调用 configure-exe.ps1。
  configure-exe.ps1       安装/恢复实现：检查版本和组件指纹、备份用户配置、
                         复制 Agent、写入用户启动参数和用户环境变量。
  local-state-agent.jar  已验证的本地运行时组件，安装入口需要此文件。
  restore-exe.cmd         可选恢复入口，还原安装前的用户启动配置。
  repair-startup.cmd      启动失败修复入口，重新校验组件并重建启动配置。
  README.txt             本说明。
  SHA256SUMS.txt         包内其他文件的 SHA-256 校验值。

使用方法
  1. 将 ZIP 全部解压到本地目录，保持上述文件在同一目录。
  2. 右键 install-for-exe.cmd，选择“以管理员身份运行”，确认输出 Configured GoLand。
  3. 保存工作，完全退出已有的 GoLand 窗口和进程。
  4. 直接双击原来的 goland64.exe 或原快捷方式。
  安装后无需每次运行脚本。旧终端等启动器可能需要重开以更新环境。
  提升权限时请继续使用当前 Windows 账号，不要切换成另一个管理员账号。

安装位置与备份
  Agent 安装到 GoLand 的独立子目录：
  C:\Program Files\JetBrains\GoLand 2026.3\local-agent
  启动参数和备份状态保存在当前用户的：
  %USERPROFILE%\.goland-state-lab\263.7307.211
  当前用户的 GoLand 自定义 VM options 也会写入对应配置。
  写入 Program Files 需要管理员权限；权限不足时停止，保留现有启动配置。
  安装不会修改 GoLand EXE 或系统级 GOLAND_VM_OPTIONS。
  安装完成后运行不依赖本解压目录，但建议保留文件以便恢复。
  新版安装器会先实际启动 Java 检查 Agent；检查失败时不会更新启动参数。
  启动参数采用原子替换写入，避免启动时读取到只写了一半的文件。
  Agent 自检日志位于上述安装目录中的 agent-startup-check.log。
  安装器验证文件实际落盘路径，避免 MSIX AppData 重定向使 EXE 找不到组件。
  旧版安装会自动迁移原始恢复记录，不把已修改的配置当作原始配置。
  运行组件以 local-state-agent-<指纹前12位>.jar 保存，便于已有进程继续使用旧版。
  更新后需要完全退出 GoLand 再重新打开，新组件才会进入新进程。
  恢复时运行 restore-exe.cmd，然后退出并重新启动 GoLand。
  恢复仅还原用户配置，不删除安装目录中的共享 Agent 文件。
  卸载或更换 IDE 安装目录可能移除该组件，需要在重新安装 IDE 后重新配置。
  若用户在安装后自行改过 VM options，恢复脚本会停止以保护这些修改。

启动失败时
  若出现 agent library failed Agent_OnLoad: instrument，运行 repair-startup.cmd。
  该报错表示 JVM 未能加载或初始化 Java Agent，不代表必须重装整个 IDE。
  修复入口会复核版本、JAR 指纹和实际 Java 加载结果，再重建用户配置。
  如果修复入口报告失败，请保留其错误输出和自检日志，勿继续覆盖配置。
